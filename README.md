# odin_rock_paper_scissors
A simple game of Rock, Paper, Scissors.

How to play:
1. Choose one of the options: rock, paper or scissors.
2. The opponent (computer) will also choose their option.
3. The results are compared and displayed on the screen.
4. The winner gets one point. In case of a tie, no one gets points.
5. The game continues until one of the players gets 5 points.
6. After the game is over, the user can start a new game.

Functionality:
1. Calculating points for the player and the computer.
2. Displaying the result of the round with the winner highlighted.
3. Stopping the game when 5 points are reached and locking the buttons.
4. Restart button to start a new game.

--

The game was updated as part of a practical exercise to learn JavaScript and DOM.
